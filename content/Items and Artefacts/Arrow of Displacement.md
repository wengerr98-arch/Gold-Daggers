# Arrow of Displacement

## Known Information

A magical arrow crafted from quartz crystal that allows the user to teleport to the location where the arrow lands. It has three uses and was received by [[Snix]] as chest loot in the infernal gate area during Session 097.

## Session Appearances

- Session 097: Snix received from a chest drop in the infernal gate area.

## Known Facts

- Material: quartz crystal.
- Effect: user teleports to the arrow's landing location when fired.
- Uses: 3.
- Current owner: [[Snix]].
- Acquired: Session 097, chest loot in the infernal gate area.
